# Brightwork AI Assistant

Build a modern, responsive SaaS web application called **AI Workplace Productivity Assistant**.

**Design:** Use a premium yellow (#FFC928), black (#111111), and white colour scheme. Create a clean dashboard with a left sidebar, modern cards, rounded corners, subtle shadows, professional icons, and responsive layouts.

**Navigation:**
1. Dashboard
2. Smart Email Generator
3. AI Research Assistant
4. AI Chatbot
5. Settings

**Features:**

**1. Smart Email Generator**
- User enters email purpose, recipient, and key details.
- Generate professional, realistic emails.
- Tone options: Formal, Friendly, Persuasive.
- Include Generate, Copy, and Edit buttons.

**2. AI Research Assistant**
- Users enter a topic or paste an article.
- Generate detailed summaries, key findings, insights, and recommendations.
- Include Copy and Edit options.

**3. AI Workplace Chatbot**
- Modern ChatGPT-style chat interface.
- Users can ask workplace-related questions.
- Provide intelligent, relevant, detailed AI-generated responses.
- Include chat history, suggested prompts, and a clear chat button.

**4. Dashboard**
- Welcome message.
- Quick-access feature cards.
- Recent activity.
- Productivity overview.

**Technical requirements:**
- Frontend only. No backend, database, or authentication.
- Use React and Tailwind CSS.
- Use local storage for saving recent activity where appropriate.
- Use structured AI prompts for each feature.
- Use real AI-generated responses through an AI API if configured. Never pretend simulated responses are AI-generated.
- If no API is configured, provide a clearly labelled demo mode.
- All generated outputs must be editable.
- Ensure all buttons and navigation work.
- Fully responsive on desktop, tablet, and mobile.

**Responsible AI:** Display a disclaimer explaining that AI-generated content may contain errors and should be reviewed before professional use.

**Important:** Prioritise functionality, simplicity, and a premium SaaS appearance. Build all features within one application. Avoid unnecessary animations and complex integrations. Do not build a backend.
